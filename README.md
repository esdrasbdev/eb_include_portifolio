# ✦ Esdras Brito — Portfolio

Portfólio pessoal desenvolvido para apresentar projetos, habilidades técnicas, experiências e tecnologias utilizadas no desenvolvimento de produtos digitais.

O projeto foi desenvolvido com foco em **design moderno, responsividade, interatividade e experiência do usuário**, utilizando uma estética minimalista inspirada em interfaces como **Apple, Vercel e Linear**.

## ✨ Preview

O portfólio apresenta uma interface predominantemente **preta e branca**, com animações, microinterações e elementos interativos ao longo da navegação.

Entre os principais recursos estão:

* Hero interativo com apresentação e foto de perfil
* Navegação suave entre seções
* Dark / Light Mode
* Animações e transições
* Efeitos de hover e parallax
* Cursor interativo no desktop
* Seção de hobbies interativa
* Timeline de formação
* Apresentação de projetos
* Stack de tecnologias
* Links para redes sociais
* Design totalmente responsivo

---

## 🧩 Seções

### Sobre

Apresentação resumida e informações principais do perfil profissional.

### Hobbies

Seção interativa desenvolvida com uma experiência orbital, permitindo explorar diferentes interesses através de elementos conectados e animados.

### Formação

Timeline com a formação acadêmica e demais experiências educacionais.

### Projetos

Apresentação de projetos desenvolvidos, incluindo sistemas, aplicações web, SaaS e experiências digitais.

### Stack

Tecnologias e ferramentas utilizadas no desenvolvimento dos projetos.

### Processo

Apresentação visual das principais etapas utilizadas na construção de produtos digitais, desde o planejamento até o deploy.

### Contato

Links para contato e redes sociais.

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/esdrasbdev/eb_include_portifolio.git
```

Entre na pasta:

```bash
cd SEU-REPOSITORIO
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

A aplicação estará disponível no endereço informado pelo Vite, normalmente:

```text
http://localhost:5173
```

---

## 🏗️ Build

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar a build:

```bash
npm run preview
```
